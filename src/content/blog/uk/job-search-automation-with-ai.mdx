## Вступ

Jobber почався як внутрішній інструмент. Інженери fluxLab.dev відстежували заявки на роботу в таблицях — губили, яке резюме куди відправили, від яких компаній отримали відповідь і які інтерв'ю наступні. Ми побудували Jobber для вирішення власної проблеми, а потім зрозуміли, що кожен шукач роботи має таку ж біль.

## Проблема

Пошук роботи хаотичний. Типовий активний шукач:

- Подає заявки на 20-50 вакансій на різних джоб-бордах
- Має 2-3 версії резюме для різних типів ролей
- Відстежує заявки в таблиці, яка стає застарілою за тиждень
- Пропускає дедлайни фоллоу-апів через відсутність системи нагадувань
- Не знає, яка версія резюме чи джерело заявок працює найкраще

## Рішення: Jobber

Jobber — персональна платформа управління пошуком роботи. Вона охоплює весь пайплайн від знаходження вакансії до відстеження результату:

### Імпорт вакансій

Користувачі зберігають вакансії з будь-якого сайту за допомогою розширення для Chrome. Коли вони натискають «Зберегти в Jobber», розширення захоплює вміст сторінки і надсилає його на наш бекенд.

Бекенд використовує тришаровий підхід до парсингу:

1. **Витягування JSON-LD** — структуровані дані з LinkedIn, Indeed, Glassdoor (45% імпортів)
2. **Зіставлення DOM-паттернів** — селектори для конкретних сайтів серед відомих джоб-бордів (30%)
3. **Claude AI фолбек** — LLM витягує деталі вакансії з необробленого тексту сторінки (19%)

Такий багатошаровий підхід забезпечує 94% успішності, тримаючи витрати на ШІ мінімальними.

### Відстеження заявок

Заявки організовані у вигляді списку та Kanban-дошки. Користувачі можуть:

- Відстежувати статус: Подано → Скринінг → Інтерв'ю → Оффер → Відмова
- Додавати нотатки та коментарі на кожному етапі
- Налаштовувати власні шаблони етапів відповідно до свого процесу співбесід
- Фільтрувати за компанією, статусом або діапазоном дат

### ШІ-конструктор резюме

Jobber включає повноцінний конструктор резюме з ШІ-допомогою:

- **Керування розділами**: досвід роботи, освіта, навички, проєкти, сертифікати
- **Генерація ШІ-саммарі**: створює професійний саммарі на основі досвіду роботи
- **Пропозиції bullet points**: генерує пункти, зосереджені на досягненнях
- **Перевірка ATS-сумісності**: гарантує, що формат резюме коректно працює із системами відстеження кандидатів

### Оцінка відповідності резюме вакансії

Користувачі можуть перевірити, наскільки добре їхнє резюме відповідає конкретній вакансії. ШІ аналізує:

- Збіг навичок (технічних і soft skills)
- Відповідність рівня досвіду
- Відсутні ключові слова
- Розбивку за категоріями

Це допомагає користувачам вирішити, чи подавати заявку одразу, чи спершу доопрацювати резюме.

### Генерація супровідних листів

Для кожної заявки Jobber генерує адаптований супровідний лист на основі:

- Опису вакансії та вимог
- Змісту резюме користувача
- Інформації про компанію

Користувачі можуть редагувати, покращувати або перегенеровувати супровідні листи за допомогою ШІ.

### Аналітика

Панель аналітики надає інсайти, яких не отримати з таблиць:

- **Воронка заявок**: конверсія на кожному етапі
- **Час на етапах**: середня кількість днів очікування на кожному кроці
- **Ефективність резюме**: які версії резюме отримують найкращий відгук
- **Продуктивність джерел**: які джоб-борди приносять найбільше співбесід
- **Відсоток відповідей**: загальний показник і показник по кожній компанії

## Технічний стек

- **Frontend**: Next.js, TypeScript, Tailwind CSS
- **Backend**: Go з chi router, pgx для PostgreSQL
- **База даних**: PostgreSQL + Redis
- **ШІ**: Claude API (Haiku для парсингу, Sonnet для генерації)
- **Інфраструктура**: Docker, Hetzner Cloud, Caddy
- **Платежі**: Paddle для підписок

## Що далі

Ми працюємо над інтеграцією з Google Calendar для планування співбесід прямо з Jobber, нагадуваннями для фоллоу-апів та системою тегів для організації заявок за пріоритетом.

## Висновок

Jobber доводить, що ШІ-функції не повинні бути всім продуктом — вони покращують надійний робочий процес. Основна цінність — це організація та прозорість. ШІ робить це швидше та розумніше. Якщо ви активно шукаєте роботу, спробуйте Jobber на [jobber-app.com](https://jobber-app.com). [Кейс Jobber](/uk/projects/jobber) детальніше розповідає про продуктову складову.
